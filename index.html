Enterprise Network Security Assessment

Junior Cyber Security Analyst Project

This project presents a simulated enterprise network security assessment and defense planning exercise.

Project Objectives

  • Identify network components
  • Identify security threats
  • Analyze network risks
  • Recommend defensive controls
  • Design network segmentation

Security Findings

ID Finding Risk
NET-01 Weak privileged credentials Critical
NET-02 Unnecessary exposed services High
NET-03 Insufficient network segmentation High
NET-04 Weak wireless security High

Defense Strategy

  • Firewall security
  • IDS/IPS
  • Network segmentation
  • Secure Wi-Fi
  • MFA
  • SIEM monitoring
  • Patch management
  • Backup and recovery
